MOUNTAIN STYLE SHOPS — WEBSITE PACKAGE

This is the complete static website. No build step or dependencies are required.

Deploy
1. Extract this ZIP.
2. Upload index.html, favicon.svg and the assets folder to the root of your web hosting.
3. Open the domain. The page uses root-relative /assets/ paths.

Local preview
From the extracted folder, run: python3 -m http.server 8000
Then open http://localhost:8000

Editing
The layout, styles and interactions are in index.html. Images and original shop logos are in assets/. Visible website copy is in English.

Important
Customer review photos and the Mountain Style storefront photo were gathered for a private design preview. Get permission from the photographers or replace these images before publicly deploying this package. See PHOTO_CREDITS.txt.
